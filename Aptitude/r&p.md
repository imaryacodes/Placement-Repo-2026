# RATIO AND PROPORTION

1. RATIO
- Ratio of 2 quantities a and b = a:b
- The multiplication or division of each term of a ratio by the same non-zero number does not affect the ratio.

2. PROPORTION
- Equality of wo ratios 
- If a : b = c : d, a : b :: c : d where a & d are 'extremes' and b & c are 'mean terms'
- Product of means (b x c) = Product of extremes (a x d)

3. PROPORTIONALS
-  Fourth Proportional: If a : b = c : d, then d is called the fourth proportional to a, b, c.
- Third Proportional: if a : b = c : d, then c is called the third proportion to a and b.
- Mean Proportional: Mean proportional between a and b is sqrt(ab)

4. COMPOUNDED RATIO 
- The compounded ratio of the ratios: 
(a : b), (c : d), (e : f) = (ace : bdf)

5. DUPLICATE RATIOS
- Duplicate ratio of (a : b) = (a^2 : b^2).
- Sub-duplicate ratio of (a : b) = (sqrt(a) : sqrt(b)).
- Triplicate ratio of (a : b) = (a^3 : b^3).
- Sub-triplicate ratio of (a : b) = (a^1/3 : b^1/3)

6. COMPONENDO AND DIVIDENDO RULE
If a:b = c:d, 
then (a + b)/(a - b) = (c + d)/(c - d)

7. VARIATIONS
- x is directly proportional to y, if x = ky for some constant k
- x is inversely proportional to y, if xy = k for some constant k
