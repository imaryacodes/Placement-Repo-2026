# TIME & WORK

1. WORK FROM DAYS
- Work = Rate × Time
- 1 Day's work * Days = Total work
- If A can do a piece of work in n days, then A's 1 day's work = 1/n
- If A's 1 day's work =	1/n, then A can finish the work in n days.
- FOR 2 PEOPLE WORKING TOGETHER, time taken = xy/(x+y)

2. RATIO
- If A is thrice as good a workman as B, then:
- Ratio of work done by A and B = 3:1
Ratio of days taken (i.e. efficiency) by A and B to finish a work = 1:3
