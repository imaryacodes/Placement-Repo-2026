# PERCENTAGES

1. PERCENTAGE INCREASE
- if increase by R percent
-  Reduction in Consumption = [R/(R+100)]*100%

2. PERCENTAGE DECREASE
- if decrease by R percent
- Increase in Consumption = [R/(100-R)]*100%

3. POPULATION RESULTS 
- if population = P, increase rate = R% per annum
- Population after 'n' years = P(1+(R/100)^n)
- Population 'n' years ago = P/(1+(R/100)^n)

4. DEPRECIATION RESULTS
- if machine value = P, depreciation rate = R% per annum
- Value of machine after 'n' years = P*(1-(R/100)^n)
- Value of machine 'n' years ago = P/(1-(R/100)^n)

5. If A is R% more than B, then B is less than A by [R/(R+100)]*100%

6. If A is R% less than B, then B is more than A by [R/(100-R)]*100%
